# ProductivAI Report Templates

AI agents should format their daily analysis and weekly review reports following these clean, consistent markdown structures.

---

## Template 1: Daily Productivity Analysis Report

```markdown
# 📊 Daily Productivity Analysis

**Overall Score: [SCORE]/100 — [CATEGORY]**
*(Evaluated via ProductivAI [ENGINE])*

---

### 🌟 What Went Well
- **[Positive Driver 1]**: [Observation with specific metric detail]
- **[Positive Driver 2]**: [Observation with specific metric detail]

### ⚠️ What Is Holding You Back
- **[Primary Limiting Factor]**: [Honest plain-English explanation of the biggest drag on focus or stamina]

### 🎯 Top 3 High-Impact Improvements
1. **[Action 1]**: [Specific delta target, e.g. Reduce social scrolling by 1 hour]
2. **[Action 2]**: [Specific sleep/exercise/break target]
3. **[Action 3]**: [Specific work session structure adjustment]

### 📋 Tomorrow's Action Plan
- **Morning**: [Concrete first step to start strong]
- **Afternoon**: [Deep focus block recommendation]
- **Evening**: [Rest & recovery guideline]

---

> 💡 **One Thing to Focus On Tomorrow**:
> *[Single highest-leverage micro-habit to avoid overwhelm]*
```

---

## Template 2: Weekly Longitudinal Review Report

```markdown
# 📈 Weekly Productivity Review

**Weekly Average Score: [AVG_SCORE]/100**
**Total Sessions Evaluated: [COUNT]** | **Peak Score: [PEAK]/100** | **Consistency Rate: [RATE]%**

---

### 🏆 Best Day vs. Worst Day
- **Peak Performance**: Day [X] ([SCORE]/100) — Supported by [key habit].
- **Friction Day**: Day [Y] ([SCORE]/100) — Constrained by [key bottleneck].

### 🔍 Behavioral Patterns & Insights
- **Most Consistent Habit**: [E.g., Sleep regularity or workout consistency]
- **Primary Source of Friction**: [E.g., Mid-week screen time spikes or irregular breaks]

### 🎯 Next Week's Benchmark Target
- **Primary Objective**: [E.g., Increase average daily study time from 3.5h to 4.5h without cutting sleep]
- **Friction Cap**: [E.g., Set a hard 1.5h daily limit on social media]
```
